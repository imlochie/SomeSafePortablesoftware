The Windows desktop build stages its Node runtime in this directory.
node.exe is generated by scripts/stage-node-runtime.mjs and is not committed.

On Windows, scripts/stage-media-tools.mjs reads the Tauri target architecture,
downloads and verifies the matching pinned portable media tools from
scripts/media-tools-manifest.json, and stages yt-dlp.exe, ffmpeg.exe, and
ffprobe.exe under media-tools/. Unsupported architectures fail before any
installer resources are produced. The API sidecar receives that directory
through ARCHIVE_MEDIA_TOOLS_DIR; explicit YT_DLP_PATH, FFMPEG_PATH, and
FFPROBE_PATH values still take precedence.
