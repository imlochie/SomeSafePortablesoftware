The Windows desktop build stages its Node runtime in this directory.
node.exe is generated by scripts/stage-node-runtime.mjs and is not committed.

On Windows, scripts/stage-media-tools.mjs downloads and verifies the pinned
portable media tools from scripts/media-tools-manifest.json. It stages
yt-dlp.exe, ffmpeg.exe, and ffprobe.exe under media-tools/. The API sidecar
receives that directory through ARCHIVE_MEDIA_TOOLS_DIR; explicit
YT_DLP_PATH, FFMPEG_PATH, and FFPROBE_PATH values still take precedence.
