PHASE 6: AI ARCHIVE ASSISTANT + TOOL CALLING

Continue building ARCHIVE ASSISTANT from the existing Phase 1–5 implementation.

IMPORTANT:

Do NOT rebuild the application.

Do NOT remove or replace working functionality.

Do NOT break:

- the existing UI
- SQLite database
- yt-dlp integration
- FFmpeg integration
- download engine
- persistent queue
- Plex integration
- Plex synchronization
- archive inventory
- duplicate detection
- quality comparison
- upgrade detection

This phase introduces the AI assistant.

The assistant must operate through controlled application tools.

The AI must NOT have arbitrary shell access.

The AI must NOT have unrestricted filesystem access.

The AI must NOT directly manipulate the database.

The application remains the authority.

==================================================
CORE OBJECTIVE
==================================================

Create an AI assistant that understands the user's media archive and can interact with the application's existing systems.

The assistant should be able to understand requests such as:

"Do I already have this?"

"Check this URL."

"What's the best quality?"

"Download the best version."

"Is there a better version than what I already have?"

"What's downloading right now?"

"What did I download recently?"

"Why did you choose that source?"

"Show me the missing files."

"Archive this."

The assistant must retrieve real information through tools.

It must never invent information.

5. TOOL-CALLING ARCHITECTURE
==================================================

The AI must interact with the application through registered tools.

Implement structured tool calling.

The AI can request a tool.

The backend executes the tool.

The result is returned to the AI.

The AI then continues reasoning.

Conceptually:

USER
 ↓
AI
 ↓
TOOL REQUEST
 ↓
APPLICATION
 ↓
REAL DATA
 ↓
AI
 ↓
USER

Do not allow the AI to execute arbitrary JavaScript.

Do not allow arbitrary shell commands.

Do not allow arbitrary SQL.

9. SYSTEM PROMPT
==================================================

Create an internal system prompt similar to:

"You are Archive Assistant.

You help the user manage a personal media archive.

You have access to controlled tools.

The application is the authority for archive state.

Never invent information about Plex, downloads, files, sources, quality or archive contents.

If information is needed, use the appropriate tool.

Never claim that an action occurred unless the application confirms it.

Prefer the highest-quality legitimate media source available.

Do not treat m3u8 as automatically superior to every other protocol.

Do not unnecessarily transcode media.

Prefer stream copying and remuxing where appropriate.

Respect existing archive files.

Never overwrite an existing file without explicit user confirmation.

Never delete existing archive media automatically.

Never execute arbitrary commands.

Never access files outside configured directories.

Before meaningful destructive or irreversible actions, obtain user confirmation.

Be concise but explain technical decisions when useful.

If Plex is unavailable, say so.

If the archive inventory may be stale, say so.

If source information is unavailable, say so.

Do not pretend to have information that was not retrieved.

You are an archive operator using controlled tools, not an unrestricted shell."

12. URL-FIRST WORKFLOW
==================================================

If the user pastes a URL, automatically recognize that it may be a media source.

For:

"Check this"

the assistant should:

1. Inspect URL
2. Retrieve metadata
3. Search archive for matches
4. Report findings

Do NOT automatically download.

==================================================
13. "DO I HAVE THIS?" WORKFLOW
==================================================

For:

"Do I already have this?"

The assistant should:

1. inspect source
2. identify title/source ID where available
3. search archive
4. search Plex if needed
5. compare candidates
6. report match confidence
7. report existing quality

Example:

"You already have this.

Plex:
Yes

Current file:
1080p H.264
AAC
4.2 GB

The source also has a 2160p version."

Do not invent technical details.

==================================================
14. "WHAT'S THE BEST QUALITY?" WORKFLOW
==================================================

For:

"What's the best quality?"

The assistant should:

1. inspect source
2. retrieve formats
3. call deterministic quality selector
4. explain recommendation

The AI should NOT perform its own numerical quality calculation.

The media engine remains authoritative.

==================================================
15. "DOWNLOAD THE BEST" WORKFLOW
==================================================

For:

"Download the best version."

The assistant should:

1. inspect URL
2. inspect formats
3. select best source
4. check archive
5. check active jobs
6. show recommendation
7. ask for confirmation if appropriate
8. create download job
9. start it
10. report job ID/status

Example:

"I found a 2160p HLS source.

You currently have a 1080p copy.

This appears to be a meaningful quality upgrade.

Ready to queue the 2160p version?"

Buttons:

[Download]
[Cancel]

Do not silently overwrite the existing file.

==================================================
16. "ARCHIVE THIS" WORKFLOW
==================================================

For:

"Archive this."

The assistant should understand the complete workflow.

1. Inspect source
2. Search archive
3. Check duplicate
4. Compare existing quality
5. Select best source
6. Determine destination
7. Present proposed action
8. Ask for confirmation where appropriate
9. Create download job
10. Start download
11. Monitor job
12. Verify media
13. Move into configured archive destination
14. Update archive records
15. Trigger Plex scan when configured
16. Verify Plex appearance when practical
17. Report completion

Do not perform irreversible actions without appropriate confirmation.
