Build a Windows-first local application called ARCHIVE ASSISTANT.

This is a personal media archive control system, not simply a video downloader.

The application should eventually combine:

- AI assistant
- Plex library inventory
- yt-dlp
- FFmpeg
- local filesystem monitoring
- media downloading
- media processing
- duplicate detection
- archive history
- quality comparison
- persistent job queue

The primary target computer is:

Intel Core Ultra 5 125H
14 cores / 18 threads
16 GB LPDDR5
Intel Arc integrated GPU
Intel AI Boost NPU
~1 TB NVMe SSD
Windows

IMPORTANT ARCHITECTURE:

The finished application must run locally on the user's Windows laptop.

Do not make Replit hosting a requirement for the finished product.

Replit is being used to build the application.

Use a modular architecture so components can be added independently.

Recommended stack:

- TypeScript
- Node.js
- React
- Vite
- Express or Fastify
- SQLite

Keep the architecture simple and local-first.
